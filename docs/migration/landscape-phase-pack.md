# Talki Landscape Redesign — Full Phase Pack

This is the execution index for the complete landscape redesign continuation.

The program runs one phase at a time. Plans/prompts are committed in advance; reports/evidence are generated by the agent at execution time and become required input to the next phase.

## How to execute

For each phase:

1. Open a fresh Claude/Cursor agent session at repository root.
2. Ask the agent to implement the phase using its committed prompt.
3. The agent must read `AGENTS.md`, `_landscape-shared.md`, the active plan, and the previous phase report.
4. Review the generated report/evidence before starting the next phase.
5. Never start the next phase automatically.

A suitable short instruction is:

> Implement Phase NN. Read and obey all repository agent instructions and execute `docs/migration/prompts/phase-NN.md` exactly. Do not start the next phase.

## Audit vs report

Only Phase 16 intentionally creates a separate `phase-16-audit.md`, because Phase 16 is the rebaseline/audit phase.

Phases 17–28 create a normal `phase-NN-report.md` containing their implementation evidence.

Phase 29 creates extra release evidence:

- `phase-29-device-matrix.md`
- `phase-29-release-checklist.md`
- `phase-29-report.md`

Phase 30 creates extra cutover evidence:

- `phase-30-cutover-checklist.md`
- `phase-30-data-migration-results.md`
- `phase-30-rollback-plan.md`
- `phase-30-report.md`

Do not pre-create empty reports/audits. They are evidence and must be written by the executing agent from actual code/tests/results.

## Important dependency rule

The plan/prompt for a later phase is a durable scope contract, **not** permission to ignore what earlier phases actually implemented.

Every phase must consume the immediately previous phase report and adapt implementation details to current source. If the previous report did not reach its required exit status, the next phase must stop BLOCKED/NO-GO as defined by its plan.

## Sources of truth

- `AGENTS.md` — repository non-negotiables.
- `docs/design/landscape/README.md` — landscape design/product contract.
- `docs/design/landscape/reference/` — approved visual references.
- current source — behavioral truth.
- active phase plan — phase scope/acceptance truth.
- previous report — actual implementation/evidence truth.
